# V1.4 讨论：大脑的优势到底在哪，自主动作怎么来

> 用户批评（2026-09-15）：现在的映射本质是程序写死——事件→通道→阈值→动作→
> 固定表演，用 166,700 神经元的连接组没有任何超过 if-else 的优势；果蝇有大量
> 自主动作（走动、自发行为序列），现在完全没有。本文用两个实测实验回答：
> 哪些优势是真的、哪些不是，以及怎么让"自主"从大脑里长出来。

## 1. 承认批评：现在"决定"发生在哪里

| 环节 | 现状 | 谁在决定 |
|---|---|---|
| 事件→通道 | encoder 写死映射表 | 程序 |
| 通道→动作 | decoder 阈值阶梯 `if DNp01>12 then JUMP...` | **程序（优先级是手写的 if 链）** |
| 自发游走 WANDER | `idle>8s 且 rng<0.004` | **程序（定时器+随机数）** |
| 情绪 | Python 计数器/EMA | 程序 |
| 动作→表演 | nya_map 查表 | 程序 |

大脑在其中只做"注入→读回"，是转发器不是决策器。批评成立。

## 2. 实验一：不给任何刺激，大脑自己会做什么（120s 无刺激记录）

- DNg100（前进）自发爆发 **47 次/120s**，单次 0.06-0.14s，间隙平均 **2.45s**
  （最长 9.7s）——这个"爆发-静默"节律恰好是果蝇走走停停的量级！
- **左偏性格**：DNa02_L 均值 0.49 vs DNa02_R 0.17——这颗种子天然偏向左转。
- DNp10（展翅）基线最活跃（p95 11.4Hz，接近 12Hz 展翅阈值）——求偶展示
  环路天然不安分。
- 但 **1s 自相关 = 0.02**：网络在秒级以上**没有记忆、没有慢状态**。自发
  波动全是亚秒级毛刺，靠它自己长不出"持续 3 秒的散步"。

**结论**：连接组有丰富的*快结构*（爆发、间隙、左右偏置、种子特异），但
*慢状态*（活动/休息节律）不存在于模型内——那在动物里由中央复合体和神经
调质负责，这个仿真没有端生出它们。

## 3. 实验二：矛盾驱动同时注入，网络会仲裁吗（竞争探针）

| 条件 | DNp01（逃跑） | DNg01（理毛） |
|---|---|---|
| 只注入理毛 | 1.5 | **24.7** |
| 理毛 + 恐吓影同时 | 46.4 | **24.5（完全没被压制）** |

两个环路**并行各自响应，零串扰**。威胁+逃跑、追逐+逃跑同样互不影响。

**结论**：这个连接组**不做行为仲裁**——没有赢者通吃。硬编码优先级阶梯
不能删给网络。"让网络解决竞争"这条优势不存在（诚实地放弃）。

## 4. 真正可收割的优势（按证据强度排序）

**A. 快结构：自主动作的"微观质感"由网络成形（证据：实验一）**
规则引擎的自主行为只有两种：太规律（定时器）或纯随机（rng）。连接组给出
第三种：**有解剖来源、通道耦合、种子特定的噪声结构**。爆发间隙分布、左右
偏置、犹豫感——这些写不出分布，但已经在模拟里。程序侧只提供一个慢变量
"活动张力"（tone，相当于神经调质/代谢状态），把张力低强度注入运动环路，
让 DNg100 的自发爆发决定何时起步停步、DNa02/03 的不对称决定方向和弯度——
走出来的轨迹是抖动的、带弯的、天生左偏的：果蝇样，且每只不同。

**B. 连续读出：动作不再是开关（已部分存在，扩到全量）**
speed←DNg100、head_angle←DNa02 已是连续。补：弯度←DNa03 不对称、展翅
强度←DNp10 连续值（不再阈值开合）。动作间过渡变成参数渐变，行为看起来
是"从神经系统里流出来的"，不是档位切换。

**C. 种子=性格（证据：实验一的左偏）**
同一套刺激序列，不同 seed 的果蝇长期行为直方图不同——性格是模拟的免费
副产品。规则引擎做不到"没写过的性格"。

**D. 泛化**：没写过的刺激组合会得到按真实连接强度的分级响应（通道并行
响应保证至少不冲突），而非规则表里查无此项。

**明确放弃/明说做不到的**：
- 网络仲裁（实验二证伪）——动作选择仍留在程序侧，但可以改成按读出分布
  加权抽样（比 if 链诚实，且是随机化的，不等于写死）；
- 学习/记忆（fly.ai 无突触可塑性）；
- 秒级以上的内生行为状态（实验一证伪）——慢状态必须由程序侧 tone 提供。

## 5. V1.4 方案：程序提供"代谢与身体"，连接组提供"此刻的神经决定"

| 层 | 谁负责 | 说明 |
|---|---|---|
| 慢状态（活动张力/昼夜/情绪基调） | 程序 | 相当于神经调质，秒-分钟级慢变量 |
| 走停时机、方向、弯度、犹豫 | **连接组** | 张力注入下 DNg100/DNa02/DNa03 的自发动态 |
| 动作选择 | 程序（按读出分布加权抽样） | 不再是 if 优先级链 |
| 连续参数 | **连接组** | speed/head/curvature/display 全连续读出 |
| 表演（Live2D） | 程序 | 不变 |

**Phase 2（自主行走）**：删掉 decoder 里的 WANDER 定时器；加 tone 慢变量
注入运动环路；校准张力→爆发→步战（bout）统计，目标 2-10s 战长、带弯度、
种子偏置。校准方法与当年 calibrate_channels 相同（测量驱动的剂量响应）。
**Phase 3**：decoder 改为按读出分布的随机抽样 + 连续参数扩容。
**Phase 4**：Lab 加"性格面板"（自发偏好直方图、两只种子对比）。

## 6. 用户能看见什么变化

- 现在：每 8-20s 匀速直线滑动 2-4.5s，急停。
- 之后：果蝇走走停停（起停是大脑的爆发决定的），路径带弯、天生偏一侧、
  偶尔犹豫；被惹毛后 tone 升高→自发表演变频繁；两只种子是两只性格。

风险照实说：自发动态的统计可能需要几轮校准才"像"；仲裁缺失意味着极端
组合仍由抽样规则兜底。
